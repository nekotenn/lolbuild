LoLビルド（スウェイン・タムケンチ ボット）

はじめに1回だけ
  make_shortcut.bat をダブルクリック → デスクトップに「LoLビルド」ができます。

ふだん
  デスクトップの「LoLビルド」をダブルクリック。
  ・黒い窓（サーバー）が出て、いつものブラウザに新しいタブでページが開きます。
  ・初回だけ、データ取得に数分かかります。
  ・LoLを起動していれば、ピック画面／ゲーム中の敵5人を自動で読みます。
  ・黒い窓を閉じると自動読み取りが止まります。

データを新しくしたいとき
  update_data.bat をダブルクリック（数分）。終わったらページを再読み込み。

フォルダは動かさないでください（動かしたら make_shortcut.bat をもう一度）。

毎週自動でデータを取り直したいとき
  auto_update_on.bat を1回だけダブルクリック（毎週日曜10時）。
  やめたいときは auto_update_off.bat。結果は update_log.txt に残ります。
